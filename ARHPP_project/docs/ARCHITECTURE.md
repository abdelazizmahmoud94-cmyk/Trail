# ARHPP Architecture

ARHPP is organized as layered engines: core, geometry, fluids, hydraulics,
flow, dynamic calculations, events, pore pressure, diagnostics, sensors,
mechanics, PLC simulation, visualization, reports, API and frontend.

The Pressure Ledger decomposes BHP and ECD into hydrostatic, friction, SBP,
surge/swab, gas, losses, kick and U-Tube-related terms.
